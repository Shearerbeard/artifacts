Initiatives and wins over time

  1. 2 commits2026-04 - Birth
    Initial repo with the Tuckr group structure, plus the foundational decision: a multi-account 1Password hook resolves secrets at shell startup instead of committing them. Every later env-var win builds on this.
  2. 33 commits2026-05 - Foundation
    README and architecture docs land; drifted configs adopted into version control. First platform-split fix: tmux's CSI-u keyboard protocol moved into platform.conf, unbreaking Cmd+V paste on macOS without touching Linux. OpenCode gains LSP diagnostics.
  3. 97 commits2026-06 - Expansion (peak month)
    The agent toolchain arrives: tmux pane-pop (per-session popups in a floax-style frame), nvim's show_file float for surfacing files from chat, the sesh dashboard, and codecompanion's move to Fireworks-hosted models. Tuckr coverage completes with global gitignore and cargo config.
  4. 74 commits2026-07 - Process and mobile
    The tracking system ships: BOARD.md plus session threads plus changelog, with a conformance audit script. Vale prose gates start biting every commit. Herdr spiked as a tmux successor; collie brings phone notifications and approvals over tailscale. Kimi K2.7 becomes the default coding model; the opencode wait_for port is researched and staged.
  5. 14 commits2026-08 - Hardening
    Ghostty F12 dropdown diagnostics (read-only failure classifier plus Spotlight launcher), collie supervision migrated to its native launchd agent (verified across reboot), the OpenCode v2 beta drive closes with parity findings, and kimi-code joins PATH on macOS. The design artifact skills land - this page is their first real output.
