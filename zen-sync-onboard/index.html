Zen sync — connect your browsers

Point your Zen browsers at the self-hosted sync store on fedora-cube. One pref per device, ~5 minutes each, no LAN ports, no firewall changes.

Connect your Zen browsers

  1. Before you start prereq
    Be on the tailnet (MagicDNS resolves fedora-cube.<tailnet> → the cube's tailnet IP). Have a Mozilla account (existing or free new one). Zen 1.23.4b on all three devices — already verified.
  2. Device 1 — notanton do first
    Set the pref → if it ever synced to Mozilla, sign out, then sign back in → about:sync must show the fedora-cube node → create a test bookmark. This establishes the baseline everything else round-trips against.
  3. Device 2 — T14 do second
    Same pref + sign-in. Expected: notanton's test bookmark arrives within seconds; the cube's bso row count grows. That arrival is the proof the backend stores and redistributes correctly.
  4. Device 3 — Mac optional
    Same steps, only if you've decided the Mac syncs. Otherwise leave it on Mozilla cloud or no sync — its inbound posture stays untouched either way.
  5. If it goes wrong revert
    Node still "mozilla" → pref set after sign-in (wrong order): revert the pref, sign out, set it, sign in. 401s in about:sync-log → tokenserver/FxA env (not a device problem — report it). TLS errors → tailnet HTTPS not enabled on the cube. Revert any device: set the pref back to https://token.services.mozilla.com/1.0/sync/1.5, sign out/in.
