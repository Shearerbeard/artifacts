Findings worth your attention

  • Worktree fallback redesigned. Codex's attack was right that the common-dir parent is not the main checkout — but its proposed fix (git worktree list) doesn't locate it either in separate-git-dir or submodule layouts: git reports the git dir itself as the first worktree, verified empirically. The resolver uses worktree list and fails loud in those layouts rather than docking to an unrelated directory. Codex accepted this on re-review.
  • Reviewer routing re-ruled in-session. The Phase 0 pin (kimi-for-coding/k3 as code reviewer) assumed a Claude author; the board's same-family rule bars it over Kimi-authored code, so GLM-5.3 + codex ran these gates.
  • One rejection. Codex flagged ruff format --check drift; rejected — the repo is not format-normalized at baseline (master fails it on pre-existing files), and ruff check is the deterministic gate. Repo-wide formatting is a separate decision.
  • Posture is the companion table's fact. --posture must agree with the posture recorded in wiki.toml; D8 (which repo gets which posture) stays reserved for the Stage 1.3 decision gate.
